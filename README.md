# CobbleSpire / slaythecoblebus

COBBLEVERSE 1.7.42 / Minecraft 1.21.1 / Fabric / Cobblemon 1.7.3용 독립 협동 로그라이크 애드온입니다. CobbleLeague·CobbleSynergy 의존성은 없습니다.

기본 진입 키는 **F10**이며 게임 키 설정에서 변경합니다. 설치된 기본 모드팩에서 F4·F6·F7·F8·F9·U는 다른 기능에 쓰이고 있어 피했습니다.

## 개발 단계

- [x] 빈 원격 저장소 복제와 독립 Gradle/Fabric 프로젝트 초기화
- [x] 원본 GDD와 JSON 정의 보존
- [x] 설치된 모든 애드온의 포켓몬·폼·기술 레지스트리 조사 및 호환성 보고
- [ ] 독립 기술 덱·에너지·협동 페이즈 전투와 검증
- [ ] 3막 지도·보상·상점·휴식·영입·보스·모험 도구
- [ ] 독립 설치 및 기존 애드온과의 공존 검증

런 상태와 포켓몬은 별도 메모리 데이터로 관리하며 기존 PC·인벤토리를 변경하지 않습니다. 콘텐츠를 조용히 흉내 내거나 미지원 규칙을 작동한다고 표시하지 않습니다. 검증되지 않은 규칙은 이유와 함께 활성화에서 제외합니다.

## 원본 자료

`design/GDD-v4.1.md`와 `design/data`가 제공된 기획의 보존 사본입니다. `design/Settings.json`, `LevelProgression.json`, `MoveUpgrades.json`은 원본 엑셀의 셀 주소를 보존한 읽기 전용 발췌입니다. 현재 수정 규칙은 GDD v4.2와 `current_rules.json`이 우선하며 v4.1은 원본 참고 자료입니다.

빌드: JDK 21에서 `./gradlew test build`.

## 현재 검증된 범위

독립 서버 로딩에서 **1,025종·1,481폼**, 기본 캐릭터 50종, 적 기술 참조 97건의 등록과 배움표를 확인했습니다. CobbleLeague와 CobbleSynergy를 제외하고 로딩했습니다.

현재 개발 버전 **0.5.1-dev**는 F10으로 대표를 선택해 단독 시험 전투를 진행합니다. 기본 손패 5장·턴 종료 버림·추가 드로우·뽑기/버림/소멸 덱·카드 이동 연출을 연결했습니다. 교체하면 이전 손패를 버리고 새 5장을 뽑습니다. 타입 무효는 ×0이며 런 능력치 성장은 없습니다. 전체 도감 조회도 유지합니다.

3막 지도·협동 참가·상점·유물은 이후 단계입니다. 원본 특수 효과는 검증된 범위만 활성화하고 나머지는 제외 사유를 남깁니다. 이 버전은 운영용 완성 릴리스가 아닙니다. 지원 범위와 재현 방법은 `docs/COMPATIBILITY.md`, 단계 결과는 `docs/validation`을 참고하세요.

현재 사용자 수정 규칙은 `design/GDD-v4.2.md`가 우선합니다. 진화는 이벤트/배지 권한 모델을 준비했으며 실제 노드는 후속 단계입니다. 개발 UI 실행은 `./gradlew runClient`이며 독립 `run-ui/`에 저장합니다.

## 전투 화면 디자인

0.4.0-dev는 `cobblespire:arena` 월드 차원에 블록 경기장과 실제 Cobblemon 포켓몬 엔티티를 생성합니다. 플레이어 몸은 측면 관전 구역에 남고, 분리된 공중 카메라가 아군/적을 비스듬히 내려다봅니다. 카드 HUD 뒤에 2D 배경이나 GUI 포켓몬을 그리지 않습니다. 방향키로 각도 조정, Home으로 시점 초기화, 닫기로 실제 관전 위치 시점, F10으로 전술 화면 복귀, 모험 종료로 원래 위치 복귀가 가능합니다. 현재 프로토콜 6이므로 서버/클라이언트 버전을 맞춰야 합니다. 상세는 [월드 전장 구현 기록](docs/WORLD_ARENA.md), 카드 스킨 이미지 출처는 [UI 스킨 작업 기록](docs/UI_SKIN.md)을 참고하세요.

## 피해 표시와 승리 전리품

0.5.0-dev는 카드의 기술 타입·기본 위력·선택 대상별 예상 HP 감소, 적의 기술 타입·예상 피해·상성·명중률, 실제 적중 피해 기록을 표시합니다. 예상치는 급소를 제외한 명중 시 범위이며 현재 대상 HP를 상한으로 합니다. 승리하면 중앙 결과 팝업에서 진행점수/부활을 확인하고, 모험 파티용 합법 기술카드 3개 중 한 장을 선택하거나 건너뜁니다. 선택한 카드만 해당 포켓몬의 모험용 덱에 추가되고 다음 전투까지 유지됩니다. 실제 파티·PC·인벤토리에는 지급하지 않습니다. [실행 화면과 검증](docs/COMBAT_FEEDBACK.md)을 참고하세요.

## 카드 역할 색상과 기술 타입 태그

0.5.1-dev는 카드 전체 색상으로 공격(주황)·방어(파랑)·지원(보라)을 구분하고, 공격 기술의 타입은 별도 태그로 표시합니다. 응원 등 비공격 카드에는 위력·명중률·피해 예측·상성·적 이름을 표시하지 않고 실제 효과와 대상만 보여줍니다. 적의 비공격 인텐트도 같은 기준을 사용합니다. [분류 기준과 실제 화면](docs/CARD_ROLES.md)을 참고하세요.
