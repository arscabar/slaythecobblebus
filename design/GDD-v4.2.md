# CobbleSpire v4.2 — 사용자 수정 규칙

v4.1 원본 자료는 보존하며, 이 문서와 `data/current_rules.json`의 변경 내용이 우선합니다.

1. 플레이어와 적 모두 타입 무효는 ×0. 다른 원본 상성 배율·특성/상태 면역은 유지합니다.
2. 기술 슬롯 방식은 폐기합니다. 턴 시작 기본 5장, 사용 후 즉시 보충하지 않고 카드 효과만 추가 드로우합니다.
3. 턴 종료 시 모든 포켓몬의 남은 일반 손패를 버립니다. 보존 효과 카드는 유지합니다.
4. 교체 시에는 보존 여부와 관계없이 기존 손패를 전부 버립니다. 들어오는 포켓몬은 항상 새로 5장을 뽑습니다. A→B→A 복귀도 이전 손패를 복구하지 않습니다. 일반 교체 에너지 1·라운드당 1회와 무료 기절 교체는 유지합니다.
5. 포켓몬별 덱을 유지합니다. 사용 카드는 버린 더미, 소멸 카드는 별도 소멸 더미로 이동합니다. 뽑기 덱이 비면 버린 더미만 섞습니다. 효과 처리 중인 카드는 아직 어느 더미에도 넣지 않아 자기 자신을 즉시 다시 뽑지 않습니다.
6. 기본 최대 손패는 시험값 10장입니다. 가득 차면 추가 드로우를 멈추며 남은 뽑기 카드를 잃지 않습니다.
7. 런 레벨의 능력치 자동 상승을 제거합니다. 원본 Lv50/IV31/EV0/중립 성격 기준 스탯은 그대로 유지하고 진행점수만 기록합니다. 성장의 주축은 카드 강화·도구·진화입니다.
8. 진화는 자동 레벨업이 아닌 특정 이벤트 또는 배지로 받은 서버 소유 권한을 사용합니다. 같은 배지/이벤트 중복 지급 금지, 원본 진화 분기 확인, 선택 실패 시 권한 보존을 적용합니다. 실제 배지/이벤트 노드는 후속 지도·보스 단계에서 연결합니다. 현재 일반 시험 전투가 임의로 진화권을 주지 않습니다.

## UI

- 왼쪽: 뽑기 덱과 남은 카드 수. 누르면 별도 창에서 목록을 보되 순서는 공개하지 않습니다.
- 오른쪽 아래: 사용/턴 종료로 버린 카드 더미.
- 오른쪽 위: 소멸 덱. 이번 전투에서 다시 뽑지 않습니다.
- 가운데 아래: 손패. 기본 5장, 추가 드로우 시 한 화면에 더 표시하며 호버로 상세를 봅니다.
- 뽑기→손패, 손패→사용 위치→버림/소멸, 버림→뽑기 셔플, 교체 시 정리/새 손패에 이동 애니메이션을 표시합니다.
- 애니메이션은 서버가 확정한 이동 기록으로만 재생합니다. 창 재열기나 패킷 재전송으로 옛 연출을 반복하지 않습니다.
- 개발용 ‘응원’: 에너지 1, 카드 2장 드로우, 소멸. 각 포켓몬 시작 덱의 유틸리티 1장을 대체합니다. 원본 포켓몬 기술과 별도인 지원 카드임을 표시합니다.
