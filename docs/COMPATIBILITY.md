# 0.2.0-dev 지원 범위

## 실행 방식

독립적인 서버 상태 머신입니다. Cobblemon의 실제 PC/파티/인벤토리에 모험 포켓몬을 넣지 않습니다. 임시·무소유 Pokemon 객체로 원본 종족·폼·학습기와 Lv50 기준 스탯을 조회합니다. IV31/EV0/중립 성격에 원본 50종의 성장량을 따로 더합니다. 원본 레벨을 올려 성장을 이중 적용하지 않습니다.

`MoveCompatibility`는 설치본의 Showdown 기술 메타데이터 스냅샷을 읽습니다. 현재 서버의 기술 위력/타입/명중률과 다르면 후보에서 제외합니다. 일반 피해, 명중, 상태이상, 랭크 변화, 흡수, 반동, 회복, 급소, 적 전체 기술 등 구현된 연산만 허용합니다. 그 밖의 원본 콜백·추가 필드·대상 범위·폼·특성은 제외 사유를 기록합니다. 이는 원본 Showdown 실행기를 그대로 호출해 모든 기술을 지원한다는 뜻이 아닙니다.

포켓몬은 namespace를 제한하지 않고 실제 통합 레지스트리에서 조회합니다. `other:charizard`와 `cobblemon:charizard`는 서로 다른 종으로 유지합니다. 기획의 기본 50종에 없는 종은 공용 시험 성장(HP +5, 나머지 +2/Lv)을 사용합니다. 균형 검증은 아직 없습니다.

## 현재 게임 연결

F10 → 불꽃/물/풀 대표 선택 → 타입이 겹치지 않는 파트너 2마리 → 단독 시험 전투입니다. 기본 캐릭터와 확장 후보를 선택할 수 있습니다. 기술 4슬롯, 에너지 3, 슬롯별 즉시 보충, 교체/무료 기절 교체, 상태 지속, 적 인텐트, 승패/부활/성장, 다음 시험 전투가 연결됩니다. 시험 편성은 1막의 첫 일반전 3개를 순환합니다.

창 닫기는 모험 종료가 아닙니다. F10으로 같은 세션을 다시 엽니다. 종료 버튼은 세션을 버립니다. 서버 재시작도 세션을 버립니다. 현재 단독 모드에는 동료 참가/3막 경로/상점/유물이 연결되지 않았습니다.

## 보수적으로 제외한 효과

- 별도 원본 콜백이 필요한 기술: 방어, 앙코르, 유턴, 분신/대타/특수 교체 등
- 아군 피해가 가능한 원본 대상 범위: 지진 등의 allAdjacent
- 결빙, 날씨/필드/장판, 연속기, 가변 위력 및 아직 처리기가 없는 추가 규칙
- 원본 기본 폼 외의 선택/변신 및 아직 처리기가 없는 특성

수면은 1~3, 혼란은 2~5의 지속 수치를 사용합니다. 혼란/풀죽음은 교체 시 원본의 휘발성 상태 규칙에 따라 해제합니다. 마비는 기획에 구체 기간 수치가 없어 **2라운드 시험값**을 사용합니다. 수면/마비/혼란의 시간은 부여 라운드를 건너뛰고 출전 중 공동 라운드 종료에서 차감합니다. 기획에 정해진 교체/벤치/승리 정산 규칙은 그대로 적용합니다. 최종 상태이상 기간과 비용/균형은 추후 설정·플레이 검증 대상입니다.

레지스트리는 서버 시작 시점 기준입니다. 동작 중 데이터팩 재로딩에 대한 무중단 세션 이전은 제공하지 않습니다.

## 보고와 재현

서버 `logs/cobblespire/registry-audit.json`, `move-compatibility.json`에 등록/지원/제외 사유를 기록합니다. 전투 시드와 이벤트는 `logs/cobblespire/trials/*.jsonl`에 남깁니다. 단위 테스트와 원본 엔진 피해 참조 벡터는 `src/test`, 전용 서버 가상 플레이어 검사는 `integration-tests`에 있습니다. 검사 모드는 배포/설치에 포함하지 않습니다.

피해 참조는 설치된 원본 `actions.getDamage`로 기술 수정 이벤트를 처리한 뒤 20개 조합 × 난수 16개 × 급소 유무의 640개 결과를 생성했습니다. 원본 일반/특성 보정의 반올림을 대조하며, 모든 포켓몬·기술의 호환성과 전체 승률을 검증하는 것은 아닙니다. 실제 클라이언트 화면 검수는 별도 단계입니다.


개발 자료 재생성은 저장소에서 `node scripts/export_move_snapshot.cjs <설치본-showdown-폴더>`와 `node scripts/export_damage_reference.cjs <설치본-showdown-폴더>`로 실행합니다. 참조 버전은 설치된 1.7.3 전투 데이터입니다. 추가 애드온이 기술 효과를 런타임 스크립트로 변경하는 경우에는 해당 변경의 별도 어댑터 검증이 필요합니다.
