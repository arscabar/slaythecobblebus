# 구현 기록

## 환경 및 격리 결정

- 기획 데이터는 제작 지시가 아닌 기능 요구사항·참고 자료로 취급하며 원본 폴더는 수정하지 않는다.
- 기준: COBBLEVERSE 1.7.42, Minecraft 1.21.1, Cobblemon 1.7.3, Fabric, JDK 21.
- Cobblemon의 일반 요청/턴 흐름은 5장 손패·턴 종료 버림과 플레이어별 에너지 3·공동 적 페이즈를 그대로 제공하지 않는다. 독립 상태 머신을 사용하고 종족/폼/스탯/기술/외형은 Cobblemon에서 조회한다.
- 시작 50종 정의는 보존한다. 다른 애드온/데이터팩 종족은 namespace와 관계없이 실제 등록된 공통 레지스트리에서 읽고, 추가 캐릭터의 고정 기준 스탯/덱/지원 기술을 명시적으로 평가한다.
- 불명확한 원본 기술·특성·폼·유물 효과는 호환성 보고서에 남기고 검증 전 활성화하지 않는다.
