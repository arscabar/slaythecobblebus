# 협동 전투 화면 구조도

논의한 내용을 시각화한 설계안이다. 게임에 구현된 화면이 아니며, 크기·카메라 각도·키 배정은 실제 플레이 테스트로 결정한다.

## 1. 공간 배치 — 위에서 본 전장

```text
                         적 진영
               [적 1]     [적 2]     [적 3]

                  기술 이동·피격 연출 공간

             [아군 1] [아군 2] [아군 3] [아군 4]
                         아군 진영

 ┌ 측면 관전 구역 ┐          ↗ 카메라 A: 전체 조망
 │ P1  P2  P3  P4 │         ↗ 카메라 B: 측면 조망
 │  선택적 의자   │        ↗ 카메라 C: 개인이 조절
 └────────────────┘
```

- 플레이어당 파티 3마리 중 **1마리만 출전**한다. 4인이라면 아군 최대 4마리와 적 최대 3마리가 전장에 선다. 대기 포켓몬은 파티 UI에서 확인한다.
- 플레이어의 실제 몸은 측면 관전 구역에 있고, 전투 카메라는 몸과 독립적으로 전장 주변을 본다. 관전 구역에서 제한적으로 이동할 수 있으며, 의자는 선택 사항이다.
- 참가자는 카메라 위치·각도·줌을 각자 조절한다. 서버가 확정한 포켓몬 위치와 전투 결과는 공통이다. 카메라는 지형이나 모델 안으로 들어가지 않도록 제한한다.

## 2. 평상시 — 전장 중심

```text
┌────────────────────────────────────────────────────────────┐
│ 라운드 3 · 아군 차례                          카메라 초기화 │
│                                                            │
│       적 A               적 B               적 C           │
│     HP ████░           HP █████           HP ███░░         │
│   공격: 나 8~12        방어 예고           전체 공격 예고   │
│                                                            │
│             포켓몬과 전투 연출이 보이는 공간               │
│                                                            │
│       아군 · 민수           나 · 피카츄        아군 · 지수  │
│        HP ███░░             HP ████░           HP █████    │
│                                                            │
│ 내 HP 68/90 · 에너지 ●●○                 전투 기록 ▸        │
│ [파티]       [카드 조작 열기]                 [턴 종료]     │
└────────────────────────────────────────────────────────────┘
```

포켓몬 이름표와 HP는 대상 가까이에 작게 표시한다. 내 출전 포켓몬은 `나`, 아군은 참가자 이름으로 구분한다. 적의 피해 예고는 기본적으로 **내 출전 포켓몬 기준**임을 명시한다. 조건부 예측과 범위는 상세에서 확인한다. 전투 기록과 파티는 접힌 상태이며, 화면 중앙에는 전체 패널을 두지 않는다.

## 3. 카드와 대상 선택

```text
┌────────────────────────────────────────────────────────────┐
│ 라운드 3 · 아군 차례                      [전체 시점 복귀]  │
│                                                            │
│      적 A              적 B                적 C            │
│    HP ████░        ◎ 선택 대상           HP ███░░          │
│                    HP █████                                │
│             전장과 대상이 계속 보이는 영역                 │
│                                                            │
│  대상: 적 B  [대상 목록 ▾]     예상 결과 · 조건 확인 ▸      │
│ ┌뽑기┐  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐  ┌버림┐       │
│ │ 12 │  │카드 1│ │카드 2│ │카드 3│ │카드 4│  │ 4  │       │
│ └────┘  └──────┘ └──────┘ └──────┘ └──────┘  └────┘       │
│ 에너지 ●●○      파티 교체         [닫기] [턴 종료]         │
└────────────────────────────────────────────────────────────┘
```

전술 모드에서 커서를 사용해 카드를 선택한다. 대상을 전장 위에서 직접 고르거나 목록·키보드로 선택한다. 카드 호버·선택 시에만 비용, 효과, 사용 불가 이유 등 상세를 보여주고 중요한 대상을 가리지 않도록 위치를 조정한다. 모드를 닫으면 실제 시점의 이동 조작으로 돌아갈 수 있다. 손패가 많거나 화면이 작을 때는 카드 영역의 크기와 스크롤을 조정한다.

## 4. 적 행동 — 연출과 결과 우선

```text
┌────────────────────────────────────────────────────────────┐
│ 적 차례                                     전투 기록 ▸    │
│                                                            │
│                     적 B · 바위날리기                      │
│                           ▼                                │
│                  기술·피격 연출 공간                       │
│                                                            │
│     민수의 포켓몬          내 포켓몬          지수의 포켓몬 │
│       −11 HP                −8 HP               −10 HP     │
│                                                            │
│ 내 HP 60/90                                      손패 ▴    │
└────────────────────────────────────────────────────────────┘
```

적 행동 중 손패는 기본적으로 접어 전장을 더 보여주고, 필요하면 펼칠 수 있다. 행동자·기술명·대상별 실제 결과를 서버가 정한 순서대로 보여준다. 화면 밖 대상의 결과는 화면 가장자리 표시와 전투 기록에서 확인한다. 애니메이션은 결과를 설명하는 표현이며 판정을 결정하지 않는다.

## 5. 참가자별 카메라와 전황

```text
   같은 서버 전장과 행동 순서
            │
     ┌──────┴──────┐
     ▼             ▼
 P1의 카메라     P2의 카메라
 높은 전체 시점  측면 확대 시점
 P1 손패·에너지  P2 손패·에너지
 P1 기준 예고    P2 기준 예고
```

모든 참가자는 같은 슬롯, HP·상태, 적 행동과 결과를 본다. 각자 카메라와 자기 손패·에너지·대기 파티를 따로 조작한다. 적의 전체 공격은 각 출전 포켓몬에 대한 예상 피해가 다를 수 있다. 각 화면에는 자기 기준 예상을 우선 표시하고, 상세에서 공개 가능한 아군별 예상치를 본다. 다른 참가자의 손패 공개 여부는 미결이다.

카메라나 큰 포켓몬 때문에 가림이 생기면 각도 조절과 기본 전체 시점 복귀를 제공한다. 그래도 보이지 않는 대상은 화면 가장자리 표시 및 대상 목록으로 접근한다. 카메라 움직임이 불편한 사용자를 위해 전환 속도와 흔들림 설정도 검토한다.

## 6. 이동·전투·다음 층 흐름

```text
분기 지도에서 다음 노드 선택
          ↓ 서버 확정
전용 전장으로 진입 → 측면 관전 구역 배치
          ↓각자 전투 카메라 조절 ↔ 실제 시점으로 구역 내 이동
          ↓
공동 전투 → 결과 확인 → 보상 등 노드 처리
          ↓
지도에서 연결된 다음 층 노드 선택
          ↓
막 보스 완료 시 다음 막 또는 최종 결과
```

지도는 걷는 월드 지도가 아니라 분기형 UI다. 층은 지도에서의 진행 깊이이며 물리적인 계단 이동을 뜻하지 않는다. 전장 구현 방식, 동률 투표, 재접속 및 안전 복귀는 서버 구현과 함께 검증한다.

## 실제 화면 검수 기준

1~4인, 적 1~3마리, 대형 포켓몬, 여러 화면비와 GUI 배율에서 전신·대상·기술 경로가 보이는지 확인한다. 서로 다른 카메라로 같은 행동 순서와 결과가 전달되는지, 화면 밖 대상과 기록을 확인할 수 있는지 검증한다. 손패를 펼친 상태와 연출 중에도 대상 선택과 전황 파악이 가능한지 실제 게임 플레이로 확인한다.


## 7. 카드를 드래그해 대상 선택

슬레이 더 스파이어처럼 카드를 눌러 대상까지 끌고 놓아 사용하는 방식을 목표로 한다. 현재 구현된 방식은 손패 클릭과 별도 적 선택이므로 드래그 방식은 아직 구현되지 않았다.

```text
┌──────────────────────────────────────────────────────────┐
│     적 A                 적 B                 적 C       │
│   HP ███░             ◎ 대상 강조          HP ████      │
│                         ▲                                │
│                         │ 조준선                          │
│                         │                                │
│          전장           │                                │
│                         │                                │
│ [뽑기] [카드] [카드]  [끌고 있는 카드]  [버림]          │
│ 에너지 ●●○                           놓으면 사용         │
└──────────────────────────────────────────────────────────┘
```

1. 내 차례에 사용 가능한 카드를 누른 채 끌면 카드가 커서를 따라가고 조준선이 생긴다.
2. 유효한 대상에 포인터를 올리면 대상의 윤곽과 이름을 강조하고, 가능하면 예상 결과와 그 조건을 보여준다. 가려지거나 화면 밖인 대상은 이름표 또는 대상 목록에 끌어 놓을 수 있다.
3. 유효한 대상 위에서 놓으면 요청을 서버에 보낸다. 서버가 턴·비용·카드·대상을 검증하고 확정한 후 실제 효과와 이동 연출을 표시한다. 처리 중에는 중복 요청을 막고 실패 이유를 표시한다.
4. 빈 곳이나 유효하지 않은 대상에서 놓거나 취소 키를 누르면 사용하지 않고 카드가 손패로 돌아간다.

단일 대상 기술은 대상 하나를 강조한다. 전체 대상 기술은 대상 군 전체를 강조하고 유효한 대상 영역 또는 별도 전체 대상 영역에 놓아 확정하는 안을 검토한다. 자신·아군 대상 기술은 해당 규칙이 허용하는 대상만 강조한다. 대상이 필요 없는 카드는 조준선 대신 전장 내 사용 영역에 놓아 확정한다. 범위와 대상 분류는 실제 기술 규칙에 따라 결정하며, 불확실한 기술을 임의로 지원 표시하지 않는다.

카메라마다 포켓몬의 화면 위치가 달라지므로 클라이언트가 현재 시점에서 보이는 대상의 화면상 위치를 계산하거나 화면을 향한 선택 판정을 이용한다. 겹치는 대형 모델이나 가려진 대상은 판정이 모호할 수 있으므로 대상 이름표·목록과 키보드 선택을 대안으로 제공한다. 드래그 중에는 카메라를 고정하고, 조작이 끝나면 다시 카메라를 움직인다. 기존 선택 후 클릭 방식도 접근성 대안으로 유지한다.

구현 검증은 우선 현재 시험 전투 화면의 적 선택 영역을 이용해 드래그·취소·서버 검증을 시험하고, 이후 전용 전장 카메라와 실제 모델 선택을 연결한다. 화면비·GUI 배율, 카메라 각도, 겹친 모델, 화면 밖 대상, 전체 대상 기술, 비용 부족, 지연·중복 요청을 실제 게임에서 검수한다. 현재 프로젝트에서 전용 카메라와 월드 모델 대상 판정은 미구현이므로 최종 조작감과 호환성은 시제품 검증이 필요하다.
