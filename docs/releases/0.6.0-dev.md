# CobbleSpire 0.6.0-dev 개발 프리릴리즈

2026-11-14 · COBB-9. 독립 검토와 테스트를 거친 개발 버전이며 안정판이나 전체 게임 기능 검증 완료 릴리즈가 아니다.

## 포함한 작업

1~4인 협동 시험 전투, 공동 턴·인원별 적 HP, 예상 피해 핑·동료 피해량, 고딕 HUD, 전용 전장, 덱 이동 연출, 승리 카드 보상, 음악/징글 21개와 아트를 포함한다. 보관된 미반영 작업을 복구해 화면을 닫아도 표시되는 HUD, F10 커서 조작, 숫자키 카드 사용, 전장 카메라 회전·높이·줌과 관전 위치 시점, 실제 효과 피드백, 취소 가능한 전원 항복 투표를 통합했다. 항복은 진행점수와 전리품을 지급하지 않는다.

GDD v4.2의 타입 무효 ×0, 기본 손패 5장/최대 10장, 턴 종료 버림, 교체 시 전량 버림과 새 5장, Lv50/IV31/EV0 고정 규칙을 유지한다. 기획 JSON의 protocol 3은 기획 스냅샷 값이며 실제 네트워크 프로토콜은 **7**이다. stash 복구·파일 포함/제외 근거는 `COBB-6-audit.md`를 참고한다.

## 의존성 및 설치 안내

- Java 21 / Minecraft 1.21.1 / Cobblemon 1.7.3 (지원 범위 >=1.7.3, <1.8).
- 빌드 고정값: Gradle 8.14.3, Fabric Loom 1.11.8, Kotlin 2.2.20, Fabric Loader 0.17.2, Fabric API 0.116.6+1.21.1, Fabric Language Kotlin 1.13.6+kotlin.2.2.20, Cobblemon Modrinth ID `kF7CvxTo`.
- 격리 서버에서 실제 로딩한 조합: Loader 0.18.4 / API 0.116.14+1.21.1 / Language Kotlin 1.13.13+kotlin.2.4.10 / Cobblemon 1.7.3. 일부 의존성이 더 최신이므로 최소 빌드 고정 버전의 로딩 검증으로 해석하지 않는다.
- COBBLEVERSE 1.7.42가 대상 환경이다. CobbleLeague·CobbleSynergy에 의존하지 않는다.

별도의 테스트 인스턴스를 백업한 후 서버와 클라이언트를 종료하고 양쪽 `mods`에 **동일한** `cobblespire-0.6.0-dev.jar` 하나만 설치한다. 이전 CobbleSpire JAR과 중복 설치하지 않는다. 의존 모드는 별도로 준비한다. `-sources.jar`, 소스 ZIP 및 QA 모드는 설치 대상이 아니다. 이 작업에서는 운영 설치·월드 변경이나 재시작을 수행하지 않았다.

## 검증 근거와 재현

검증 후보 커밋: `df863f50d529abe55fe6045865b26d831c4260fc`. COBB-7 독립 검토는 승인(중대/치명 결함 없음)이다. COBB-7과 COBB-10이 각각 clean 빌드에서 17 suites / 73 tests, 실패·오류·건너뜀 0과 위의 동일 JAR을 재현했다. COBB-10은 격리 전용 서버를 실제 실행해 모드 로딩, 1111 forms 등록, 전장 차원 생성과 정상 저장 종료를 확인했다. Cobblemon 자체의 선택 mixin 대상 없음, data fixer 미등록, README 리소스 경로 오류 로그는 남아 있다.

JDK 21 및 쓰기 가능한 Gradle 캐시를 준비한 뒤 소스 루트에서 실행한다. 최초 의존성 다운로드에는 네트워크가 필요하다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build_slay.ps1 -JavaHome '<JDK21>' -GradleUserHome '<GradleCache>'
# 독립 clean 빌드
.\gradlew.bat clean test build "-Porg.gradle.java.installations.paths=<JDK21>" --no-daemon --console=plain
# QA 모드 컴파일만 수행 (게임 smoke 실행과 구분)
.\gradlew.bat -p integration-tests build "-Porg.gradle.java.installations.paths=<JDK21>" --no-daemon --console=plain
```

Linux/macOS는 JDK 21에서 `./gradlew clean test build --no-daemon --console=plain`을 실행한다. 결과 JAR은 `build/libs/`, JUnit XML은 `build/test-results/test/`에 생성된다. Gradle 9 비호환 deprecated feature 안내가 있으나 Wrapper 8.14.3 빌드는 통과했다.

최종 패키징 커밋은 후보 위에 릴리즈 문서만 추가한다. `MANIFEST.json`에 후보와 최종 커밋, 태그 `v0.6.0-dev`, 소스 ZIP 및 파일 해시를 구분해 기록한다. 최종 소스 ZIP은 최종 커밋의 `git archive`이며 게임 소스·리소스·빌드 설정과 JAR은 검증 후보와 동일하다. `SHA256SUMS`로 첨부 파일을 검증한다. 상세 실행 기록은 별도 증빙 첨부에 제공하며 최종 ZIP에는 서버·월드·캐시·로그·의존 JAR·원본 머신 전용 스크립트·런타임을 넣지 않는다.

## 알려진 결함 (Low, 이번 패키징에서 유지)

- 처치각 핑 테두리 강조색의 알파 누락으로 강조가 투명하다.
- 긴 제목/토스트와 상단 버튼이 겹칠 수 있다(좌표 계산상 4~20px).
- 동료가 턴 종료한 뒤 마지막 포켓몬이 반동으로 기절하면 자동 공동 턴 전환이 지연된다. **기절한 참가자가 ‘턴 종료’를 누르면 재개된다.** COBB-10에서 실제 클래스 실행으로 재현했다.
- PileScreen에서 복귀할 때 동맹 행동 갱신이 다음 패킷까지 지연될 수 있다.
- `.gitignore`의 `/.agents/` 항목이 누락돼 있다. 런타임 파일은 명시적 파일 선택 및 패키징 검사로 제외했으며 이 결함 자체는 유지했다.

## 미검증·미완성 범위

`/spiresmoke`는 Carpet 부재로 **미실행**이다. QA 모드 컴파일 성공을 smoke 통과로 계산하지 않는다. F10·숫자키·클라이언트 mixin 실제 적용·카메라 복원·접근성·실제 아트/음악 표시와 성능·실제 2~4인 연결 플레이는 미검증이다. 파티/PC/인벤토리 보존과 네트워크·보상 UI의 실제 결과도 추가 게임 검증이 필요하다.

3막 지도·공동 경로 선택·상점·휴식·유물·진화 이벤트 노드는 미완성이다. 전투 순환과 아트·음악 번들이 전체 로그라이크 진행 완성을 뜻하지 않는다. 공개 게시 여부는 별도 결정하며 이 패키징은 Git 반영과 개발 프리릴리즈 파일 전달 단계다.
