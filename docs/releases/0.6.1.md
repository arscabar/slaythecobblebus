# CobbleSpire 0.6.1 정식 릴리즈

2026-11-14 · v0.6.1. `CobbleLeague 0.8.2` 통합 안정 배포(`CobbleLeague 0.8.2` + `CobbleSynergy 0.4.2` + `CobbleSpire 0.6.1`)에 맞춘 정식 버전입니다.

## 주요 변경 사항

- **정식 버전 전환 (`0.6.1`)**: `0.6.1-dev`의 `-dev` 접미사를 제거해 SemVer 상위 정식 버전(`0.6.1 > 0.6.1-dev > 0.6.0-dev`)으로 게시합니다.
- **속도 기반 행동 게이지 (HSR 방식 AV 턴제)**: 포켓몬의 스피드에 따라 행동 게이지(Action Value)가 차오르며, 속도가 빠른 포켓몬이 선행동 및 추가 턴을 확보합니다.
- **모험 지도 및 위치 버그 수정**:
  - 모험 종료 후 재진입 시 캐릭터가 이전 위치에 멈춰 있던 버그를 수정했습니다.
  - 한 막당 높이를 10~15행으로 확장하고 스크롤 가능한 지도 화면(`SpireMapScreen`)을 적용했습니다.
- **전투 UI / 피드백 개선**:
  - 뽑기/버림/소멸 덱을 카드 덱 스택으로 표현(뽑기 덱 크게, 소멸 덱은 버림 덱보다 작고 어둡게)하고 호버 시 미리보기를 제공합니다.
  - 적 의도 카드 기본 접힘 상태에서 HP·예상 피해량·타입 상성 외곽선(효과 굉장 은은한 노란빛, 매우 굉장 붉은빛 퍼짐)을 표시하고, 상태이상·랭크 변화 아이콘 및 마비·화상 등 부가효과 적용을 반영했습니다.
  - 좌상단 로그 표기는 직접 열지 않으면 최신 1건만 표시합니다.
  - 모험 종료 흐름 및 일시정지 UI를 개선했습니다.
- **다타수 기술 및 협동 멀티 기능 보완**:
  - 다타수(Multihit) 기술 효과·라벨·상성 검증(`MoveCompatibility`, `NativeEffects`, `BattleKernel`)을 추가·강화했습니다.
  - 협동전 연결 끊김/재접속 복구, 다중 대기실 페이징 및 새로고침, 핑 쿨다운 격리(`TrialService`, `SpireMenuScreen`, `CoopScalingTest`)를 구현했습니다.

## 의존성 및 설치 안내

- Java 21 / Minecraft 1.21.1 / Cobblemon 1.7.3 (`>=1.7.3, <1.8`).
- `CobbleLeague 0.8.2` 통합 릴리즈의 온라인 자동 업데이터 및 `CobbleLeague-friends-0.8.2.zip`에 함께 포함되어 배포됩니다.
