# CobbleSpire 전체 이미지 제작 인계서

이 문서는 이미지와 화면 자산의 전체 제작 범위를 다른 시스템에 전달하기 위한 인덱스다. 현재 구현 여부, 기획 데이터와 시제품 제안을 구분한다. 기존 이미지가 모두 존재하거나 콘텐츠가 완성됐다는 뜻은 아니다. 구체적인 사건과 조우 요청은 [이벤트 이미지 인계서](EVENT_ART_HANDOFF.md), [비전투 이벤트 전체 기획](EVENT_ART_FULL_CATALOG.md)을 함께 전달한다.

## 공통 방향과 납품 규칙

- 포켓몬 모험과 선택의 긴장을, 블록형 환경과 굵은 잉크선·각진 형태·거친 음영의 독자적인 그림으로 표현한다. [이벤트 삽화 기준](art_reference/event_pokeball_concept.png)은 무드 참고다. 특정 게임의 그림이나 인터페이스를 복사하지 않는다.
- **장면 그림과 UI 부품을 분리한다.** 장면에는 문구·버튼·수치를 넣지 않는다. 프레임·버튼·아이콘은 따로 만들고, 텍스트와 상태는 게임이 그린다. 손패·지도 노드·유물 UI의 동적 내용은 배경에 구워 넣지 않는다.
- 아래 크기는 제작 기준 제안이다. 화면 배치와 GUI 배율 시험 후 결정한다. 배경·장면은 16:9 1920×1080 이상, 별도 아이콘·부품은 투명 PNG와 원본을 제공하며 해상도는 실제 화면에서 선명하게 보일 만큼 충분하게 작업한다. 확대 가능한 프레임은 모서리·변을 분리하거나 9분할 가능하게 만든다.
- 고정 포켓몬 삽화가 실제로 선택한 파티와 충돌하지 않게 한다. 현재 초상화는 등록된 Cobblemon 모델을 그리는 방식이다. 모든 종을 별도 이미지로 재생성할 필요는 없으며 폼·스케일·사용 권한과 대체 처리를 검증한다.
- 참가자 자격, 투표·선택·보상과 피해 등은 서버 및 기획 규칙이 결정한다. 그림에 결과를 확정하지 않는다. 그림에 포함된 저작물의 배포 권한은 별도 검토한다.

## 지도: 펼쳐지는 배경과 동적 레이어

[지도 배경 시안](art_reference/map_background_concept.png)은 **선·노드가 없는 단일 배경**이다. [동작 시제품](map_prototype.html)은 배경 위에 선과 노드를 별도로 그리며, 지도 접기/펼치기, 아래에서 위로 스크롤하는 세로 분기 경로, 새 경로 생성, 도달 가능한 노드 선택을 시험한다. 시제품은 브라우저에서 독립 실행되며 마인크래프트 모드나 서버와 연결되지 않는다. 임시 무작위 경로·층 수·아이콘은 실제 규칙이 아니다.

| 자산 | 제작 요구와 장면 | 적용 위치 / 상태 |
|---|---|---|
| MAP-BG-ACT1 | 글자·경로·노드 없는 양피지, 가장자리에 블록형 숲·낡은 지형, 중앙 낮은 대비 | 1막; [map_background_concept.png](art_reference/map_background_concept.png) |
| MAP-BG-ACT2-M | 동일한 구도·안전 영역, 가장자리에 화산·검은 바위 | 2막 마그마 경로; [map_background_act2_m.png](art_reference/map_background_act2_m.png) |
| MAP-BG-ACT2-A | 동일한 구도·안전 영역, 가장자리에 해안·잠긴 유적 | 2막 아쿠아 경로; [map_background_act2_a.png](art_reference/map_background_act2_a.png) |
| MAP-BG-ACT3 | 동일한 구도·안전 영역, 차가운 유적과 보랏빛 | 3막; [map_background_act3.png](art_reference/map_background_act3.png) |
| MAP-SCROLL | 지도 펼침/접힘의 양쪽 손잡이, 종이 가장자리·그림자. 배경과 별도, 늘어날 때 깨지지 않게 | 지도 열고 닫을 때; 제안 |
| MAP-NODE-SET | 일반전·엘리트·상점·휴식·보물볼·물음표·보스·현재 위치·핑, 각 아이콘을 독립 투명 자산으로 제작 | 지도 노드; 제안 |
| MAP-NODE-STATES | 기본·선택 가능·호버·선택·현재·방문·불가·포커스. 색 외 모양/테두리로 구분 | 노드별 동적 표시; 제안 |
| MAP-PATH | 선·방향·선택/방문 상태는 좌표에 따라 코드로 그림. 이미지에 길을 고정하지 않음 | 서버 확정 지도; 동적 |
| MAP-COOP | 참가자별 핑·선택 상태를 구분하는 작은 마커, 이름은 게임 텍스트 | 협동 지도; 정책 미확정 |

지도 시제품의 이전 완성 화면 이미지는 배경에 경로가 그려져 있으므로 **구현 자산으로 사용하지 않는다**. 서버가 지도와 도달 가능 경로를 확정하며, 시드와 규칙·투표·이탈 처리는 별도 설계한다. 지도와 경로를 걷는 월드로 만들지 않는다. 실제 화면에서는 긴 지도의 스크롤, 작은 해상도, 키보드 포커스, 색각 구분, 텍스트 확대와 모션 감소를 검증한다.

각종 기술, 도구, 포켓몬에 대해 위 표는 이미지 **제작 방식**을 정하는 목록이다. 165개 도구는 개별 원본 ID와 이름·효과를 읽고 아이콘별 묘사를 작성해야 하며, 이 문서에서 모든 개별 도구의 도안을 확정한 것은 아니다. 정의 데이터와 현재 사용 가능 콘텐츠가 다를 수 있으므로 활성화 여부를 확인한다.

## 공통 생성 요청

```text
자산 ID / 화면 / 확정 또는 후보:
제작 유형: 독립 장면, 배경만, 투명 아이콘, UI 부품 중 하나
사건 또는 기능: <하나만 구체적으로>
구도·중심 대상·포켓몬 종과 폼: <확정값만>
블록형 환경 / 분위기 / 조명 / 색:
필요한 여백, 분리 레이어, 상태 및 크기:
제외: UI가 아닌 장면에는 글자·아이콘·버튼·테두리 없음.
지도 배경에는 추가로 선·노드·경로·문자 없음.
공통: 워터마크·타 게임의 실제 이미지 복제·고어 없음.
```

## 우선순위와 검수

1. 현재 시험 전투를 위한 카드·더미·전투 정보 및 선택 상태를 실제 화면에서 검수한다.
2. 독립 지도 배경·노드 아이콘·경로 그리기·지도 펼침을 시제품으로 검증한 뒤 서버 지도와 연결한다. 생성 결과의 연결성·도달 가능성·임의성은 게임 로직에서 별도 테스트한다.
3. 실제 확정된 이벤트부터 배경·삽화를 제작하고 설명/참가 조건과 별도로 연결한다.
4. 막별 전장과 기술 연출, 나머지 유물별 아이콘을 콘텐츠와 우선순위 확정 후 순차 제작한다.
5. 각 결과물은 ID, 버전, 승인 상태, 제작/생성 프롬프트·도구·날짜, 원본·출력과 배포 권리 검토 상태를 인계한다. 누락 시 진행이 막히지 않도록 대체 자산을 준비한다.

샘플 지도 배경 생성 방식: 내장 이미지 생성 도구, 2026-11-11. 프롬프트 요지: "unfolded parchment, Minecraft blocky forest at edges, quiet empty center, no paths, nodes, text, UI or creatures". 시제품은 시각적 동작 검토용이며 게임 기능은 아니다.
